# year_scrape — Full Year ArXiv Corpus

Scrapes, embeds, and stores all cs.AI papers from the past 365 days.
Provides a fallback search when the daily pipeline returns too few papers.

## Quick Start

```bash
cd year_scrape
pip install -r requirements.txt

# Step 1: Scrape papers (takes ~30-60 min due to rate limiting)
python scraper.py

# Step 2: Generate SPECTER2 embeddings
# With Modal GPU (real embeddings):
python embedder.py
# Without Modal (mock embeddings for testing):
python embedder.py  # auto-falls back to random vectors

# Step 3: Load into the backend's PostgreSQL
python db_loader.py --dry-run    # preview
python db_loader.py              # insert for real

# Test the fallback search
python fallback_search.py --limit 5
```

## File Structure

```
year_scrape/
├── config.py            # Environment config (reads backend .env)
├── scraper.py           # ArXiv bulk scraper → data/papers.jsonl
├── embedder.py          # SPECTER2 batch embedder → data/embeddings.npy
├── db_loader.py         # Loads corpus into PostgreSQL papers table
├── fallback_search.py   # Cosine similarity search (local or DB mode)
├── requirements.txt
├── README.md
└── data/
    ├── papers.jsonl     # One paper per line (generated by scraper)
    ├── embeddings.npy   # (N, 768) float32 array (generated by embedder)
    └── index.json       # Maps numpy row index → paper_id
```
